# Prompt 策略设计对比（未实测）

用户选择完全离线的固定模板，因此本程序没有大模型输入，也没有基于 Prompt 生成的样本。下表只比较三种可能的提示设计，**不能作为课程要求的真实生成质量比较结论**。

| 策略 | 如果接入模型，可以如何设计 | 假设优势 | 待真实实验验证 |
|---|---|---|---|
| 零样本 | 提供角色、年龄、主题和 JSON 结构 | 提示简短 | 格式完整性与情节质量 |
| 少样本 | 同时提供完整 JSON 示例 | 可展示期待的结构 | 是否照搬示例，输出是否改善 |
| 角色扮演 | 设定儿童文学作家兼绘本分镜师 | 提醒模型关注适龄性和视觉描述 | 是否比其他方法更适合儿童 |

`samples/` 的三个 JSON 是实际运行本地程序得到的不同主题结果，并非上述三个策略的模型输出。若课程严格要求 Prompt 实验，需经老师同意替代方案，或使用一个可访问的大模型并补充真实同条件实验和评价。
