# 角色一致性方案与效果检查

## 人物设定

以第 2 周 `forest.json` 为依据：小月是七岁孩子，黑色短发、蓝色黄色星星帽、黄色外套和红色背包；狐狸栗栗是橘色毛发、白色尾尖、绿色小包。视觉风格为温暖的水彩和色铅笔儿童绘本。

## 制作方法

使用 Codex 内置图像生成功能先生成第 1 幕，将其作为后续三幕的**角色和画风参考图**。后续每次同时重复角色外貌描述和具体动作，分别生成独立图片；这属于参考图加固定描述方案，不声称使用 IP-Adapter、LoRA 或固定 seed。图片生成并非由此项目的 Python 排版脚本调用。

## 场景对比

| 场景 | 画面内容 | 角色检查 |
|---|---|---|
| 1 相遇出发 | 小月与栗栗走进萤光森林，远处是风铃树 | 蓝帽、黄色星星、黄外套、红背包；狐狸绿色小包和白色尾尖清楚 |
| 2 发现线索 | 两位朋友观察缠住风铃的藤蔓 | 关键服装、狐狸配色与参考图一致；画面变为蹲姿和近景 |
| 3 合作行动 | 小月解开藤蔓，栗栗扶住低处树枝 | 角色外观延续；狐狸拟人化站立，前爪的动作与真实狐狸不同 |
| 4 庆祝归来 | 风铃重新响起，两位朋友庆祝，小月拿着笔记本 | 两者主要外貌、衣着与配饰延续；风铃装饰细节比前图更丰富 |

四张图并排可查看：[第一幕](../images/scene-01.png) · [第二幕](../images/scene-02.png) · [第三幕](../images/scene-03.png) · [第四幕](../images/scene-04.png)。目视检查可以辨认为同一孩子与狐狸，但面部、狐狸体态和道具细节并非像素级一致；尚未进行儿童用户测试或量化评价。

## 实际生成提示词

第一幕：儿童绘本横幅；温暖水彩和色铅笔；发光森林、蘑菇和萤火虫；七岁小月和橘色小狐狸遇见并去帮助安静的风铃树。小月黑短发、蓝色黄色星星帽、黄色外套、红色背包；狐狸橘色毛、白色尾尖、绿色小包；不要文字、水印或边框。

后三幕均将第一幕作为角色和画风参考，重复上述外貌和画风，并分别指定：①观察缠绕风铃的藤蔓；②小月解开藤蔓、狐狸扶住树枝；③风铃响起、两人庆祝、小月拿着笔记本。要求儿童友好、森林环境、无文字与水印。
