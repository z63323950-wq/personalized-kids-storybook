# 音色、角色与情绪方案

| 角色 | Windows 中文语音 | 角色设定 | 语速 |
|---|---|---|---|
| 旁白 | Microsoft Huihui Desktop | 讲述与场景转换 | 默认 -2；安静为 -3，轻快为 -1 |
| 小月 | Microsoft Yaoyao | 七岁孩子，好奇、细心 | 默认 -2；惊喜 -1，轻声 -3 |
| 小狐狸栗栗 | Microsoft Kangkang | 友好、乐于帮助 | 默认 -2；兴奋 0 |
| 森林精灵露露 | Microsoft Huihui | 给出线索、协助朋友 | 默认 -2；惊喜 -1 |

音量均为 Windows SpeechSynthesizer 的 100；音调使用各系统语音默认值。`Rate` 是 Windows 的 -10～10 相对刻度，并非百分比。除表中列出的情绪外，其他标签均使用默认 -2。情绪标签并不会作为口播文字读出。

旁白与露露是不同的系统语音名称，但二者的实际听感可能相似；三个故事角色小月、栗栗、露露分别使用三个不同的系统语音。情绪目前主要靠台词内容和有限的语速变化表达，不能保证有丰富的喜怒哀乐。请以完整试听为准。

## 实际技术检查

- 本机列出并选择上述四个语音，合成 31 段并拼接；音频编码 MP3、22050 Hz、单声道、128 kbps。
- FFprobe 测得 433.693 秒；非静音音频的平均音量约 -23.5 dBFS，峰值约 -0.9 dBFS。音量统计不等于发音质量评价。
- 逐句时间轴源于合成片段的实际 WAV 帧数，每句后添加 0.45 秒静音；浏览器测试了指定时间高亮和点击第 21 句跳转。
- 语音未配背景音效；未由真人或独立听众完成逐句听审。
