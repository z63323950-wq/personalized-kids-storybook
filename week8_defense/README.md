# 第 8 周综合展示与答辩材料

项目：星梦故事屋与离线多模态故事创作。课程要求现场演示，不能只放录屏。

## 使用顺序

1. 阅读 [`demo-guide.md`](demo-guide.md)，提前检查运行环境并练习五分钟现场演示。
2. 参考 [`talk-track.md`](talk-track.md) 准备三分钟项目讲解与两分钟问答。
3. 使用 [`architecture.md`](architecture.md) 解释实际数据流；按照 [`assessment.md`](assessment.md) 的证据和缺口审查提交。
4. 根据本人实际经历补充 [`ai-collaboration.md`](ai-collaboration.md) 的人工审查、耗时和反思。不得声称未做过的人工操作。
5. 本目录及第 2～7 周尚未加入 Git 或推送到 GitHub；推送前先检查素材、个人信息和老师要求。
