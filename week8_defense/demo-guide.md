# 现场演示操作卡（约 5 分钟）

在正式答辩前至少演练一次；下列时间是建议，不代表已经完成现场演示。现场演示使用实际交互，录屏仅作故障备用。

## 事先准备

- 保持项目目录完整；Windows 下需要 Node.js、Python、已安装的依赖，播放音频需可用扬声器。首次安装参考各周 README。
- 打开 PowerShell，运行以下命令启动第 1 周网页；关闭窗口会停止服务。

```powershell
cd 'E:\AIGC作业\personalized-kids-storybook'
npm run dev
```

- 打开另一个 PowerShell 窗口，启动素材检索：

```powershell
cd 'E:\AIGC作业\personalized-kids-storybook\week6_asset_search'
python app.py
```

- 浏览器分别打开命令行显示的网页地址（通常是 `http://127.0.0.1:5173` 和 `http://127.0.0.1:5179`）。如果端口被占用，以启动提示为准。预先打开第 3 周 `storybook/index.html`、第 4 周 `output/index.html` 和第 5 周视频，确认文件可访问及声音正常。

## 现场操作

| 时间 | 操作 | 讲述重点 |
|---|---|---|
| 0:00–1:20 | 在故事网页输入名字、年龄和兴趣，选择森林，生成后选择一条路线 | 年龄和兴趣影响本地规则；选择影响后续内容 |
| 1:20–2:05 | 打开森林绘本，展示连续两幕和一致的帽子、背包 | 图片由内置图像工具生成；参考首图保持角色特征 |
| 2:05–2:45 | 打开同步阅读页面，播放几句并点击另一句跳转 | Windows 本地 TTS，31 段逐句时间轴；声音请提前检查 |
| 2:45–3:15 | 播放故事视频的一小段，展示插画、配音、背景音乐和字幕 | 画面是静态插画剪辑，字幕对应句子时间 |
| 3:15–4:00 | 在素材检索输入“机器人恐龙探索太空星球” | 说明 TF-IDF 根据素材描述检索，不是 CLIP |
| 4:00–5:00 | 展示已生成的第 7 周森林案例的 `story.json` 与 `workflow-log.json`，指出初稿后名字、场景被改动；如现场时间允许，使用下面命令运行一次并在提示时修改 | LangGraph 固定规则流程；图片复用，不能称为自主模型 Agent |

现场运行工作流会产生新文件，选择未使用的输出目录：

```powershell
cd 'E:\AIGC作业\personalized-kids-storybook\week7_story_agent'
python -X utf8 agent.py --idea '小狐狸在森林寻找风铃' --name 小月 --age 7 --out cases/live-demo
```

出现提示后，例如名字输入“小星”、场景输入“蘑菇山谷”，主题直接回车保留。等待语音、视频生成完成，再打开输出目录；如果 `cases/live-demo` 已存在，换一个新目录名。第 7 周自动化生成耗时受机器影响，提前实测，时间不够时直接展示已有案例和日志。

## 故障备用

- 如果 Node 端口占用，使用启动时实际打印的 URL；检索端口可通过 `python app.py --port 5180` 改变。
- 若音频无声，检查系统输出设备与音量，备用播放 `week4_audiobook/output/story.mp3`；素材和流程仍应尽量现场演示。
- 若临时故障无法现场运行，向老师说明原因，使用第 1 周 `docs/demo.mp4` 或第 5 周视频辅助；录屏本身不等于完成现场演示要求。
